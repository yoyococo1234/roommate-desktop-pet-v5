# 室友桌宠 V5

一个 Windows 便携桌宠应用。支持站立、坐姿、侧身爬行三种形象切换，并会使用本人音色播放对应台词。

## 功能

- 透明无边框桌宠窗口
- 主要停留在桌面底部，低速移动
- 双击人物：站立 → 坐姿 → 侧身爬行循环
- 爬行时根据方向自动水平翻转
- 可拖动、暂停、隐藏和退出
- 系统托盘菜单
- 右键菜单“喊爸爸”
- 启动、站立、坐姿、爬行、暂停、继续、回来和“爸爸！”语音

## 运行

双击：

```text
室友桌宠.exe
```

或：

```text
启动桌宠.cmd
```

退出：

- 右键人物 → 退出桌宠
- 右键系统托盘图标 → 退出
- 双击 `退出桌宠.cmd`
- 快捷键 `Ctrl+Alt+Q`

其他快捷键：

- `Ctrl+Alt+P`：暂停/继续
- `Ctrl+Alt+H`：隐藏/显示

## 技术结构

- `.NET Framework + WPF + WinForms`
- 无第三方运行时依赖
- 人物素材为透明 PNG
- 台词语音为本地 WAV
- 运行时不联网

源码位于：

```text
source/PetApp.cs
source/AssemblyInfo.cs
```

## 制作说明

人物姿势使用开源 PhotoMaker V1 与 RealVisXL V4.0 在本机生成，并通过本地 InsightFace 人脸融合提高相似度。语音使用开源 XTTS-v2 和一段经授权的 11 秒参考音频进行本地音色克隆。

仓库不包含微信原始照片、参考音频、模型权重或本机绝对路径。

## 隐私与使用

本项目包含特定人物的肖像与克隆音色，仅适合在获得当事人授权的前提下使用。详细说明见 [PRIVACY.md](PRIVACY.md)。
